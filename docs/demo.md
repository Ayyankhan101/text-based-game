# Demo Video Description

## Overview
Demo video (8-10 minutes) showcasing the Wolf Pack Survival Adventure Game features, including three distinct storylines, achievements system, and both terminal and GUI modes.

## Segments
1. **Introduction (1 min):** Start game, explain controls (A/B choices, U undo, S save, L load, I inventory, V use item, P pack, E achievements, Q quit), menu system.
2. **Story Selection (1 min):** Demonstrate three storylines (Classic, Survival, Pack), show different starting conditions.
3. **Story Branching (2 min):** Make 5-7 decisions in Classic storyline, show different paths, demonstrate decision consequences.
4. **Stats & Day System (1.5 min):** Show stat updates (health, hunger, energy, reputation, spirit), day counter progression, daily food consumption.
5. **Events & Pack System (1.5 min):** Trigger random events (bear attack, found berries), show pack recruitment and loyalty system.
6. **Inventory Management (1 min):** Collect items, display inventory, use items by number, show automatic food consumption.
7. **Undo & Save/Load (1 min):** Use undo to backtrack, save/load game with multiple slots, demonstrate auto-save feature.
8. **Achievements System (0.5 min):** Show achievement tracking and unlock notifications.
9. **GUI Mode (1 min):** Switch to Qt GUI, demonstrate visual stat bars, buttons, and interface.
10. **Conclusion (0.5 min):** Recap all features, highlight 84+ nodes across storylines and 93+ endings.

## Technical Details
- Recorded both console and GUI gameplay with narration.
- Demonstrates all DSA structures in action (binary tree, priority queue, linked lists, stack, queue, hash set).
- Shows comprehensive game systems integration.
- Highlights balanced gameplay across difficulty levels (Easy, Normal, Hard).
- Demonstrates three complete storylines with different mechanics.
