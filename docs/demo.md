# Demo Video Description

## Overview
Demo video (8-10 minutes) showcasing the Wolf Pack Survival Adventure Game features.

## Segments
1. **Introduction (1 min):** Start game, explain controls (A/B choices, U undo, S save, L load, I inventory).
2. **Story Branching (2 min):** Make 5-7 decisions, show different paths, reach one ending.
3. **Events & Stats (2 min):** Trigger random events (bear attack, found berries), show stat updates, death condition.
4. **Undo & Save/Load (2 min):** Use undo to backtrack, save mid-game, load and continue.
5. **Inventory & Actions (1 min):** Collect items, display inventory, multi-turn hunting action.
6. **Multiple Endings (1 min):** Brief show of different outcomes (pack formation, death).
7. **Conclusion (1 min):** Recap features, show code structure.

## Technical Details
- Recorded console gameplay with narration.
- Demonstrates all DSA structures in action.
- Highlights balanced gameplay and narrative depth.
